# Awei's Blog

Just for learning and fun.

Implemented by Claude and Codex.

Claude: For init design of web UI.
Codex : For the architecture of web.

## 檔案結構

```text
bytelog_split/
├── index.html          # HTML 結構與文章內容
├── css/
│   └── styles.css      # 所有樣式、主題變數、RWD
└── js/
    └── app.js          # 搜尋、篩選、分頁、彈窗、快捷鍵等互動
```

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

## 建議維護方式

- 修改畫面結構或文章內容：編輯 `index.html`
- 修改顏色、排版、RWD：編輯 `css/styles.css`
- 修改互動功能：編輯 `js/app.js`
